the one rule behind everything

The Gold Rule

Minimise anxiety. Maximise the ability to show off.

What this actually means

Two technicians can sit the same assessment with the same skills and walk out with different grades. The variable is not Excel knowledge — it's the ability to talk about the work confidently. The Pass-grade candidate completes the task. The Distinction-grade candidate completes the task and tells you why each click happened.

This pack is built around that observation. Every chapter has a Say It Out Loud section that practises the narration. Every named device — the Cleaning Sequence, the Polish Pyramid, the Three Questions Before You Delete — is something you can say out loud to an assessor and have them tick a box.

What "showing off" doesn't mean

It doesn't mean being arrogant, or talking endlessly, or memorising scripts. It means: narrating your reasoning as you work. Out loud. Calmly. Once a day for nine days. By Day 10 it's automatic.

SHOW THIS OFF

Every chapter from here on has a green SHOW THIS OFF badge like this one. When you see it, that's a moment the assessor is actively looking for. Practise the wording out loud — not the technical action underneath, the sentence. The sentence is what gets graded; the click is just the proof.

ASSESSOR FAVOURITE

The most common reason capable candidates fail to hit Distinction isn't a technical gap — it's silence during a demo. Assessors can only grade what they can hear. Saying the next thing you're about to click, before you click it, is the cheapest grade-uplift in the whole programme.

silence vs narration · two columns

What "showing off" sounds like

Same task. Same clicks. One candidate stays silent; the other narrates. The first scores Pass; the second scores Distinction. The clicks are identical — only the running commentary changes.

Instead of silence… Try saying out loud…
(clicks Get Data, picks the file, clicks Connection Only) "I'm loading all five files as Connection Only so the pipeline stays auditable and refresh-safe."
(scrolls through subscriber_id column, spots an oddity) "Row 47 has a different format — that would break the merge silently if I didn't catch it now."
(right-clicks Remove Duplicates) "Group By first confirmed these were migration duplicates — so removing them is justified, not reflex."
(builds a PivotTable) "Region in Rows, plan_type in Columns, count of record_id in Values — answers the cross-tab question without ten nested SUMIFs."
(presses Refresh) "One click and the whole pipeline reruns — that's why the upstream work matters."

By Day 9, sentences like these will be muscle memory. Practise one per day in the Say It Out Loud section of each chapter.

RED FLAG · HEADS-UP BEFORE DAY 1

If you're working on a Mac, Excel for Mac's Power Query is missing some features the Windows version has — most importantly, From PDF. Day 1 includes a PDF file (the viewer survey) and Day 6 uses some PivotChart features that behave differently on Mac. Workarounds are flagged inside each chapter when they're needed.

If you're using Excel for the Web, Power Query is read-only — you can refresh queries but you can't author them. For this programme you need Excel for Windows desktop or a workaround setup explained on Day 1.

How each day works

Every workpack from Day 1 onwards follows the same six-part structure. Learn it once, follow it nine times. Total time per day: about 60 minutes.

Section Time What it is
The Brief2 minOne paragraph: what today's about and why it matters.
Today's Strategyread onceThe named device — the Cleaning Sequence, the Polish Pyramid, etc.
The Task30–40 minStep-by-step instructions using the StreamWave data. Click by click.
Say It Out Loud10 minPrompts you answer aloud, as if the assessor is in the room. This is where distinction is built.
The Fun Bit5 minA puzzle, reveal or quick recap that locks the day in.
Done WhenchecklistThree or four things that must be true before you move on.

If you run over on the Task, cut the Fun Bit. Never cut Say It Out Loud — that's where the grade lives.
